# SymPort

**Веб-пространство для Nokia E52, E72, N95, N95 8GB, N97 mini, N8, E7 и 7610:** телефон, файлы, контакты, музыка,
приложения и восстановление старых функций Symbian S60 — в одном месте, плюс инструменты разработки.
Интерфейс Nokia Classic: русский и английский, светлая тема в оригинальных цветах Nokia, меню из шести групп
([NAVIGATION.md](docs/NAVIGATION.md)).

**Два режима интерфейса.** По умолчанию включён **режим пользователя**: контакты, сообщения, файлы, музыка и рингтоны, темы,
приложения, резервные копии, восстановление функций. Переключатель над меню включает **режим разработчика**: прошивки,
SDK, эмулятор, зависимости, патчи и экспериментальные инструменты. Выбор запоминается в браузере.

![Обзор устройства: Nokia E52](docs/screenshots/overview-e52.png)

Поддерживаемые модели: [E52 / E72](docs/FIRST_CONNECTION_E52.md), [N95 / N95 8GB](docs/NOKIA_N95.md) (FP1, Symbian 9.2)
и [N97 mini](docs/NOKIA_N97_MINI.md) (S60 5th, Symbian 9.4). Модификация определяется по суффиксу модели и коду RM;
обычная `N95` остаётся неопределённой, а обычная N97 не считается mini. Список моделей — в
[DEVICE_MODELS.md](docs/DEVICE_MODELS.md).

[Nokia 7610](docs/NOKIA_7610.md) — оригинальная модель 2004 года (S60 2nd Edition, Symbian 7.0s, экран 176×208; не 7610 Supernova)
с собственной графикой. Это более старая платформа, чем у остальных моделей: правила S60 3rd/5th на неё не переносятся,
функции определяет транспорт, проверка пакетов остаётся `unknown`, темы и восстановление не поддерживаются.

[N8 / E7](docs/NOKIA_N8_E7.md) — отдельные профили семейства Symbian^3, без автоматического
назначения Belle. Работа с реально доступными USB-томами, файлами, медиа и пакетами; PIM — только
по результатам проверки транспорта. В режиме разработчика доступны анализ пакетов и подготовка
Reborn/Delight с VPL и JSON-отчётом. Прошивальщик и редактор тем Belle отсутствуют.

## Запуск

Образ `ghcr.io/grayhex/s60modern` собирается и публикуется при каждом изменении `main`. Способы установки:

| Где | Как |
|---|---|
| Docker / Docker Desktop | `tools/install.sh` (Windows: `.\tools\install.ps1`) — собирает образ и запускает SymPort |
| Portainer, UGREEN, NAS | один Compose-файл без клонирования: [DEPLOY_PORTAINER.md](docs/DEPLOY_PORTAINER.md) |
| Proxmox VE | LXC-контейнер с Docker одной командой: [DEPLOY_PROXMOX.md](docs/DEPLOY_PROXMOX.md) |

```bash
git clone https://github.com/grayhex/s60modern.git
cd s60modern
tools/install.sh
```

Откройте **http://127.0.0.1:8765**. Установщик проверяет конфигурацию, создаёт `.env`, собирает образ и запускает
SymPort. Другой порт задаётся в `.env` через `SYMPORT_HTTP_PORT`. Обновление: `git pull` и повторный запуск
установщика; данные лежат в именованных Docker volumes и сохраняются. Проверка без запуска:
`tools/install.sh --check`. [Установка, хранение данных и HTTPS](docs/DOCKER_DEPLOYMENT.md)

По умолчанию порт доступен только на loopback хоста. Для удалённого доступа есть три пути: SSH-туннель, HTTPS-прокси с
аутентификацией либо **Home LAN** для домашнего NAS — `SYMPORT_ACCESS_MODE=lan`, `SYMPORT_BIND=<IP NAS>` и собственный
`SYMPORT_ADMIN_PASSWORD`: SymPort покажет экран входа по адресу `http://<IP-NAS>:8765/`, без SSH и прокси. Режим включается
только явно, без пароля не запускается, работает по обычному HTTP (не открывайте порт в интернет и не пробрасывайте его на
роутере). Пошагово для UGREEN/Portainer: [DEPLOY_PORTAINER.md](docs/DEPLOY_PORTAINER.md#4-ugreen--portainer-home-lan-без-ssh-и-прокси).

## Подключение телефона

1. [Скачайте установщик Windows Bridge](https://github.com/grayhex/s60modern/releases)
   (`SymPortBridge-Setup-x.y.z.exe`, теги `bridge-vX.Y.Z`) и сверьте SHA-256 с `SHA256SUMS.txt`.
2. Запустите установщик: установка для текущего пользователя, без прав администратора. Обновления Bridge
   предлагает сам из меню трея — всегда с вашего подтверждения.
3. Откройте **Мой телефон → Подключение**: мастер первого подключения проведёт по шагам
   (проверка Bridge, запрос доступа, USB, идентификация, возможности).
4. Подключите Nokia, выберите **PC Suite**, нажмите **Найти телефон**.

Агент подключается к серверу исходящим соединением: входящий порт на Windows и ручной SSH-туннель не нужны.
Установщик пока без цифровой подписи (SmartScreen покажет предупреждение — сверяйте SHA-256), USB-драйверы
Nokia ставятся отдельно. На Linux доступны локальные транспорты и PC Bridge; карту памяти можно подключить через
`compose.phone.yaml`. Mass Storage даёт файлы карты, а не контакты, SMS или внутренний `C:/`: функции
появляются только там, где их поддерживает выбранный транспорт.

[Windows Bridge](docs/WINDOWS_BRIDGE.md) · [USB, Bluetooth и совместимость](docs/TRANSPORTS.md) ·
[Первое подключение E52/E72](docs/FIRST_CONNECTION_E52.md)

## Что можно делать

### Мой телефон

| Раздел | Возможности |
|---|---|
| Обзор устройства | Карточка модели, прошивка/RM, транспорт, накопитель, показатели из подключения (батарея, сигнал, сервисы), последняя копия и журнал операций за 7 дней. Незарегистрированное показывается как «не сообщается»; IMEI скрыт |
| Файловый менеджер | Список/сетка, поиск, сортировка, предпросмотр, скачивание, загрузка, создание папок и подтверждаемое удаление — то, что поддерживает транспорт. Существующие файлы не перезаписываются |
| Контакты, SMS, календарь | Чтение, поиск, редактирование, дубли, Google CSV и vCard, iCalendar, экспорт и синхронизация с предпросмотром; отправка SMS — с подтверждением |
| Медиа | Фото, видео и музыка: миниатюры, фильтры, предпросмотр, ZIP. Мастер **«Подготовить для Nokia»**: конвертация видео (FFmpeg), музыки и фото под экран и ограничения выбранной модели, экспорт и безопасное копирование |
| Резервные копии | Файловые копии томов, выбранные папки и личные данные через Bridge, **«Настройки и базы»**: экспорт контактов, календаря, задач и SMS с манифестом, проверкой хеша и восстановлением по одному хранилищу |

### Восстановление

Группа **«Восстановление»** собирает всё, что возвращает старой Nokia полезные функции. Копирование файла на
телефон здесь никогда не называется установкой: её завершает пользователь на экране телефона.

| Страница | Что делает |
|---|---|
| Центр восстановления | Что удалось определить по подключению, рекомендации для модели, история |
| Сеть и TLS | Современные TLS-компоненты (MBedTLS, патч системного SSL), матрица применимости по моделям и стекам, диагностика соединения и часов, безопасное копирование с точками отката |
| Набор приложений | Проверка места и транспорта, копирование проверенного набора |
| Онлайн-сервисы | Реестр старых системных адресов и их замен, проверка замен, журнал «до/после» |
| Reborn для N95 | Пошаговая подготовка Reborn Hybrid CFW (alpha): допуск по модели, импорт и проверка SIS, предпросмотр изменений, согласия, чек-лист после установки |
| Дополнения и патчи | Необязательные дополнения под модель, Patch Manager, системные патчи — закрытая категория |
| После установки | Сохранение исходного состояния, сравнение и чек-лист наблюдений |

![Центр восстановления](docs/screenshots/revive.png)

Основа — **Recovery Safety Net**: план → снимок → копирование → проверка → откат только собственных файлов по
хешу → отчёт. Подробности — [REVIVE.md](docs/REVIVE.md); Reborn и N95 — [NOKIA_N95.md](docs/NOKIA_N95.md).

## Основные сценарии

**Вернуть HTTPS на старой Nokia:** Восстановление → Сеть и TLS → проверьте часы телефона и модель → безопасно
скопируйте MBedTLS (и при необходимости патч SSL) → завершите установку на телефоне → запустите диагностику.

**Рингтон:** загрузите MP3/M4A/MP4 или нажмите «Создать рингтон» в медиагалерее → выделите фрагмент → настройте
звук → скачайте или передайте. Рингтон назначается в настройках телефона.

**Фильм или музыка для Nokia:** Медиа → «Подготовить для Nokia» → выберите модель и предустановку → конвертация →
экспорт либо безопасное копирование на карту.

**Контакты из облака:** выгрузите Google CSV / vCard → загрузите в «Контакты» → проверьте поля и дубли → план
синхронизации → подтвердите. Если доступна только карта памяти, передайте vCard и сохраните их на телефоне.

**Резервная копия:** сохраните данные до изменений. Прямая запись личных данных требует актуального плана, копии
исходного состояния и проверки чтением.

## Данные и безопасность

Сообщения, контакты и IMEI не попадают в обычный журнал. Опасные действия требуют подтверждения, неопределённые
записи не повторяются, файлы пользователя никогда не перезаписываются молча. Записи в системные разделы и
обход защиты телефона в SymPort нет; запись прошивки отключена. Возможности SymPort зависят от того, что реально
сообщает подключение; границы описаны в [LIMITATIONS.md](docs/LIMITATIONS.md), статусы — в [STATUS.md](docs/STATUS.md).
